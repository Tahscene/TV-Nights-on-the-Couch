<h2>Project Overview</h2>

<p>
As part of the <b>CSE4204: Computer Graphics Lab</b> final project, the objective was to 
design and implement an interactive 3D scene using <b>Three.js</b>. 
The project demonstrates modern computer graphics concepts including shaders, lighting, 
textures, animations, and user interaction.
</p>

<hr>

<h2>Core Features</h2>

<ul>
  <li>Custom shaders for enhanced object appearance</li>
  <li>Realistic lighting models and illumination effects</li>
  <li>Perspective projection for depth perception</li>
  <li>Texture mapping applied to all scene objects</li>
  <li>Smooth animations for dynamic visuals</li>
  <li>Mouse and keyboard interaction support</li>
</ul>

<hr>

<h2>Project Specific Features</h2>

<ul>
  <li>Textured 3D couch model</li>
  <li>Lamp stand with realistic texture</li>
  <li>Camera movement around the couch for scene exploration</li>
  <li>Dynamic couch texture changing through interaction</li>
  <li>Smooth lamp light on/off animation effect</li>
</ul>

<hr>

<h2>Technologies Used</h2>

<ul>
  <li>Three.js</li>
  <li>JavaScript</li>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>WebGL</li>
</ul>
